# mljs
This is a JS library that provides ML capabilities on browsers using ONNX runtime web.

Below is a list of features available:
1. Spatial image 


### Spatial image
This lets you convert images into [spatial image](https://www.youtube.com/shorts/GnGNgEK2nZM) on browsers. To do this, you need to embed your `image` element into a `div` element:

```html
<div id="target_div">
    <img src="/your/image/src">
</div>
```

and simply pass the `div` element to the library:

```js
const div_container = document.getElementById("target_div");
spatial_scene.convert_single_image(div_container, 4);
```

To achieve this, there are two models used:

1. [Depth Anything V2](https://github.com/DepthAnything/Depth-Anything-V2)
2. [MI-GAN](https://github.com/picsart-ai-research/mi-gan)

The ONNX binaries for these models can be found at this [HuggingFace repository](https://huggingface.co/Rocketjumper-sniped/spatial-scene)

## How to use the library for testing purposes
Currently, as `package_loader` hasn't been implemented yet, you need to do the following to use the library:

1. Create a directory called `model_binaries` in the root directory & put the models there.
2. Run the browser with web security disabled. For Chrome:

```bash
# On Windows
"C:\Program Files\Google\Chrome\Application\chrome.exe" --disable-web-security --disable-gpu --user-data-dir="C:\chromeTemp" --enable-features=SharedArrayBuffer

# On Linux
google-chrome --disable-web-security --user-data-dir="/temp/dev/" --enable-features=SharedArrayBuffer
```
